# OrbitPlans 🚀

OrbitPlans is a modern, minimalist productivity app designed to help you organize your life in one pla

Built with React Native and Expo, OrbitPlans aims to make productivity simple, beautiful, and accessible.

**Status:** 1St release 2.0.0

Made with ❤️ by the OrbitApps team.

All of the data is stored on your phone/tablet loccaly!
